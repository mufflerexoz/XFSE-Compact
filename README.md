# XFSE-Compact
Combination of UI from Xbox Series Dashboard and XBOX app Full Screen Experience for Playnite full screen themes.

Disclaimer: Icon, avatar, wallpaper, live wallpaper and video is based on the internet not fully mine inside this theme. Some of the media is directly from Xbox Series. Some code assisted by Cloude Code to improve some element in this theme. Based code its from Playnite itself.

Installation of theme.
Playnite 10. Support in 16:9 ratio (1080P). Theme can be downloaded .pthm

Addon required:
1. ExtraMetaData
2. Theme Options

Setting in playnite:
1. Game cover square 1:1 ratio
2. Show game tittle
3. Vertical 3 row
4. Filter support Recent Played, Completed, Favourites & All. (Xbox, Nintendo, Playstation)

Features:
1. Button prompt for Xbox or Playstation.
2. Theme color Xbox/Nintendo/Playstation.
3. Profile set.
4. Wallpaper set.
5. StoreFront lookalike. (Can be disabled)
6. Real playnite Total Playtime!
7. Real playnite Completions Status!
8. Real playnite total games count!
9. Hidden games will not count!
10. Universal Store app shortcut!

The XBOX badge will auto change if reach the tier of total play time.
1. Tier 1 badge (Novice) - (1-50hrs)
2. Tier 2 badge (Beginner) - (51-200hrs)
3. Tier 3 badge (Gamertag) - (201-500hrs)
4. Tier 4 badge (Insanity) - (501-1000hrs)
5. Tier 5 badge (King) - (1001hrs)

To change custom Background/Profile/ProfileBG
1. …/Images/Wallpapers/Image4.png or Live4.mp4
2. …/Images/Profiles/Avatar2.png - Avatar4.png
3. ...Images/ProfileBGS/BG3.png
